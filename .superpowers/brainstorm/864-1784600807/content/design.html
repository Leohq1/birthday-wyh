Design Overview — Birthday 3D Experience

Vite + Three.js • Semi-realistic cake • Microphone blowing • Love letter reveal

🎬 Scene Flow

Phase 1: Idle

Cake rotates slowly. Candles flicker with animated flame shaders. Petals drift down. Flowers ring the base. A subtle prompt: "Blow into your microphone to light up the candles..."

User sees the scene, hears nothing yet

Phase 2: Blowing

User blows into mic (or holds spacebar). A wind meter appears. Candle flames react to audio intensity — leaning, flickering more. Meter fills over ~3-4 seconds of sustained blowing.

Interactive — real-time audio feedback

Phase 3: Extinguish

Meter full → all candles go out at once. Puffs of smoke particles rise from each wick. Scene dims slightly. Brief pause for effect.

~2 second dramatic beat

Phase 4: Letter Reveal

3D envelope floats down from above. Flap opens. Paper slides out and unfolds. Text from config.json appears letter-by-letter (typewriter effect). Scene stays dimmed in background.

Emotional payoff — user reads the message

🔧 Key Technical Choices

Three.js Renderer

WebGL with post-processing (bloom/glow on candles). OrbitControls disabled during blow phase, subtle auto-rotation otherwise.

Audio Pipeline

Web Audio API → AnalyserNode → RMS volume calculation → smoothed value mapped to wind strength. Mic permission requested on first user click/tap.

Particle Systems

Falling petals use a BufferGeometry point cloud. Candle smoke uses sprite-based particles. Both GPU-friendly, no physics engine needed.

Text Rendering

Letter text via CSS overlay (HTML div) — not rendered inside Three.js. Simpler, better typography, easier to style. The envelope/paper are 3D but the text is HTML CSS.
